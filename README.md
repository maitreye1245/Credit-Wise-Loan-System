Credit Wise Loan System
Overview

Credit Wise Loan System is a machine learning-based application that predicts whether a loan application is likely to be approved based on applicant information such as income, credit history, loan amount, and other factors.

Features:-
Loan approval prediction
Data preprocessing and cleaning
Machine Learning model training
User-friendly prediction interface
Performance evaluation using metrics

Technologies Used:-
Python
Pandas
NumPy
Scikit-learn
Matplotlib
Jupyter Lab
